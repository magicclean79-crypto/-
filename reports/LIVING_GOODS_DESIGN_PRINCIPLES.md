# 생활용품 카테고리 — 디자인 원리 · 규칙 · 와이어프레임

> 목적: IKEA·다이소몰·지그재그를 흉내 내기 위함이 아니다. 실제 Playwright 캡처 53건
> (IKEA Korea 22건, 다이소몰 29건, 지그재그 2건 — 시도 63건 중 성공)을 화면 단위로
> 직접 관찰한 기록에서 "사람이 왜 그 레이아웃을 보기 좋다고/신뢰간다고 느끼는지"의
> 원리만 추출한다. 이 문서는 조사 결과이며, 코드/Template은 건드리지 않았다.
>
> 아래 각 원리는 이번 53건 데이터에서 **2개 이상의 사례에서 반복 관찰된 것만** 원리로
> 승격했다. 단 1건에서만 나온 것은 원리로 올리지 않고 각주로만 남겼다.

## (a) 원리 (WHY) — 근거 기반 디자인 원칙

### 1. 리뷰 "수"는 평점보다 더 강력한 신뢰 신호로 취급된다
페이지들은 평점(4.x)보다 리뷰 **건수**를 훨씬 크고 자주 노출한다. 건수가 크면
평점이 낮아도 그대로 노출한다.
- RINNIG 청소용 장갑 S/M(`rinnig-cleaning-gloves-...-40565855`, `-90565853`): 리뷰
  1242건/1243건이 "구매 확신을 주는 핵심 근거"로 명시됨.
- TÅSJÖN 슬리퍼(`tasjoen-slippers-grey-90392027`): 리뷰 1894건(시리즈 최다)인데
  평점은 4.3(시리즈 최저)임에도 큰 숫자를 그대로 노출 — "리뷰 수는 많지만 평점이
  상대적으로 낮아 신뢰 신호가 다소 엇갈림."
- SKOVELSJÖN 슬리퍼(`skovelsjoen-slippers-beige-50512989`): 1436건, "인테리어형
  사진과 압도적 리뷰 수로 신뢰를 주지만..."
- 다이소 신축 먼지클리너 계열(`pdNo=1022703`): 상세 콘텐츠는 다른 다이소 페이지보다
  짧지만(스크롤 3800px vs 평균 7000px) 리뷰 252건을 신뢰 지표로 크게 내세움.

**예외**: 리뷰가 극히 적을 때는 이 패턴이 역효과다. PEPPRIG 먼지떨이커버 옐로
(`pepprig-duster-cover-yellow-30567628`)는 리뷰 **1건**·평점 5.0인데도 다른 페이지와
동일한 크기의 별점 블록을 그대로 노출해 "콘텐츠 볼륨 대비 신뢰도 정보가 빈약해
보임"으로 관찰됨. PEPPRIG 대걸레(`pepprig-squeeze-clean-flat-mop-grey-30569854`)도
리뷰 45건·평점 3.5로 "다른 페이지보다 신뢰 신호가 약한 상세 페이지"로 관찰됨.

### 2. 배경색과 제품색을 맞춘 "톤온톤" 사진이 완성도 인식과 함께 나타난다
- PEPPRIG 청소솔 그린(`pepprig-scrubbing-brush-set-of-2-green-90567649`): 그린 배경
  위 그린 제품 — "8개 페이지 중 배경-제품 컬러 매칭이 가장 세련되고 평점도 가장
  높아(4.7) 비교군 중 완성도 있는 PDP로 보임."
- PEPPRIG 극세사천 그린/블루/옐로(`-20567638`)와 극세사 청소패드 그린
  (`-40567642`): 각각 웜톤 주방/욕실 타일 배경에 제품 컬러를 얹어 "사용 맥락"과
  "색 대비"를 동시에 전달.
- 다이소 3색 청소솔(`pdNo=1043146`): 대리석 질감 배경 위 블루/퍼플/그레이 3색을
  나란히 배치해 색 구성 자체가 정보이자 비주얼 포인트가 됨.

(인과관계까지 증명된 것은 아니고 상관관계 수준의 반복 관찰이다 — 다만 3개 이상
사례에서 "배경-제품 색 매칭 = 더 세련됨"이라는 관찰자 평가가 함께 따라왔다는 점은
유의미하다.)

### 3. 기능·작동 원리를 증명해야 하는 제품은 클로즈업 "사용 장면(액션샷)"이 스튜디오 단독컷 다음에 필수로 붙는다
- FRUKTPLOCKARE 린트브러시(`fruktplockare-lint-brush-...`): 손으로 기기를 쥐고
  실제로 옷을 미는 액션 데모 컷이 히어로 자체로 사용됨.
- RINNIG 청소용 장갑: 싱크대에서 냄비를 씻는 손 클로즈업이 히어로 — "제품 용도를
  즉시 전달."
- 다이소 2WAY 세탁조 청소솔(`pdNo=048036467/048036485`): 솔 헤드 클로즈업 →
  손으로 잡고 사용하는 장면 순으로 "형태 → 그립감/사용법"을 순차 증명.
- 다이소 옷걸이(`pdNo=1047666`): 후크 부분 클로즈업으로 걸림 방지 기능을 시각적
  으로 증명(사진으로 "설명"이 아니라 "증거"를 제시).

**예외**: 형태/무드가 핵심인 인테리어형 제품(슬리퍼·바구니)은 이 클로즈업-증명형
사진 대신 아래 원리 4의 스타일링 사진을 쓴다 — 즉 이 원리는 "기능성 제품"에
국한된다.

### 4. 인테리어/라이프스타일형 제품은 소품을 곁들인 "공간 속 제품" 무드컷을 쓴다
- SKOGSSALLAT 슬리퍼(`skogssallat-slippers-red-white-striped-50611423`): 핑크
  러그 + 배경에 걸린 옷/가방까지 함께 노출한 무드컷 — "단순 제품샷이 아닌
  라이프스타일 무드 컷으로 특징-사진 연결을 강화."
- SKOVELSJÖN 슬리퍼(`-50512989`): 헤링본 우드 바닥 + 옐로 러그를 배경 소품으로
  배치.
- TORKIS 접이식 바구니(`torkis-flexi-laundry-basket-...-70579163`): 바구니 안에
  실제 채소·과일을 담아 "실내/실외 겸용"이라는 특징을 사용 시나리오로 시각화.
- 지그재그 청바지 옷걸이(`zigzag.kr/catalog/products/136123661`): 옷걸이+청바지가
  걸린 랙 전체를 크림톤 배경으로 무드감 있게 촬영.

**예외**: TÅSJÖN 슬리퍼(`-90392027`)는 소품 없는 가장 미니멀한 단독컷이었는데도
시리즈 내 리뷰 수가 가장 많았다(1894건) — 무드 사진이 구매량/리뷰량 자체를
결정짓는 필수조건은 아니며, 카테고리 관습(convention)에 가깝다.

### 5. 표 형태 스펙 테이블은 이 카테고리에서 사실상 존재하지 않는다
53건 전체에서 전통적인 key-value 표 디자인은 하나도 관찰되지 않았다. 대체 수단은
세 가지로 반복된다.
- 아코디언 텍스트: IKEA 전체(예: `slibb-hanging-clothes-peg-green-10567733`)는
  "소재 및 관리"를 접힌 아코디언 링크로만 제공.
- 아이콘+짧은 문장 체크리스트("Daiso check point" 유형 박스): 다이소 옷걸이
  (`pdNo=1046664`), 방향제(`pdNo=1053427`), 세탁솔(`pdNo=048036467`),
  먼지떨이(`pdNo=1036957`) 등 10건 이상에서 반복.
- 그래픽 오버레이형 스펙: 다이소 쓰레받기(`pdNo=24791`)는 COLOR 원형 스와치 +
  SIZE 실루엣 비교 이미지로 옵션을 시각화, 다이소 슬리퍼(`pdNo=1023094`)는
  "약 230mm ±10mm" 사이즈를 큰 컬러 그라디언트 배경 위 대형 타이포로 강조.

### 6. 구매 액션(가격/버튼)은 제품 정보·사진보다 항상 화면 상단 먼저 배치된다(플랫폼 무관)
- IKEA SLIBB 빨래집게(`-10567733`): "가격→수량 선택/장바구니→교차판매 배너→
  (그 다음에) 실제 제품 이미지→소재/관리 정보→고객 리뷰" 순.
- IKEA PEPPRIG 청소세트(`-60567622`): "담기 버튼(가격)/수량 선택 → 교차판매
  배너 → 탑다운 히어로" 순으로 동일.
- IKEA 쓰레받기(`pepprig-dustpan-broom-grey-green-70567631`): 사진이 렌더링 전인
  상황에서도 "12,900"이라는 가격 텍스트가 문구 위치를 대신 차지함 — 사진 유무와
  무관하게 가격이 구조적으로 최상단.
- 다이소 대부분 페이지: "가격/평점 → 구매버튼 → (베스트상품 캐러셀) → 상세이미지"
  순서가 29건 중 대다수에서 동일하게 관찰됨.

### 7. 교차판매(함께 구매하면 좋은 상품) 캐러셀은 리뷰보다 먼저, 구매결정 초반부에 배치된다
- IKEA: 거의 모든 페이지에서 "교차판매 배너"가 히어로 이미지 등장 **이전**에
  위치(예: `pepprig-microfiber-cloth-00575639` 등 다수).
- 다이소: `pdNo=1025528`, `pdNo=1046664`, `pdNo=1071306` 등에서 "추천상품/베스트
  상품 캐러셀"이 구매버튼 직후, 상세 이미지·체크포인트보다 먼저 등장.
- 다이소 `pdNo=1057908`(우산꽂이): "구매액션 영역 → 베스트상품 캐러셀 2단 →
  상세 이미지" — 리뷰 섹션은 맨 마지막.

### 8. 가격대가 낮은 소모품일수록 "가격+즉시구매"가 최우선, 가격대가 높은 스타일링형 제품일수록 "감성 사진"이 최우선이다
- 다이소 빨래집게(`pdNo=1017380`, 2,000원 / `pdNo=58856`, 1,000원): 가격이 최상단
  가장 큰 볼드로, "저가 어필 → 평점 → 즉시구매 → 교차판매" 순으로 가격이 설득의
  1번 요소.
- 다이소 세탁솔(`pdNo=048036485`, 1,000원): "저가와 높은 별점 먼저 노출"이 요약에
  명시.
- 지그재그 슬리퍼(`zigzag.kr/catalog/products/142234779`, 15,900→11,610원):
  가격보다 "발+슬리퍼 클로즈업의 감성적 아웃도어 무드 사진"이 먼저 나오고,
  "감성적 무드샷으로 구매욕 자극 → 할인가/쿠폰" 순으로 감성이 1번 요소.
- 지그재그 옷걸이(`-136123661`): 브랜드 무드 생활샷이 가격/할인 정보보다 시각적
  비중이 훨씬 큼.

### 9. 청소 효과를 주장하는 제품은 "사용 흔적/전후 상황"이 보이는 사진으로 효과를 암시한다
- 다이소 롤클리너(`pdNo=1011598`): 사진 순서가 "패키지 → 사용 전 상황(먼지가
  떨어진 바닥) → 사용 손동작"으로 명시적인 전/후 스토리텔링.
- IKEA PEPPRIG 대걸레(`pepprig-squeeze-clean-flat-mop-grey-30569854`): 타일
  바닥 위에서 청소 중 물기 자국이 보이는 사용 연출컷으로 "청소 효과를 암시."

### 10. 디자이너/브랜드 크레딧(이름+인물 사진) 노출은 신뢰를 보강하지만, 저가·도매형 채널(다이소·지그재그)에서는 쓰이지 않는다
- IKEA에서 5건 이상 반복: PEPPRIG 대걸레류(`-20527096`, 디자이너 Iina
  Vuorivirta), TORKIS 바구니(Henrik Preutz), SKOGSSALLAT 슬리퍼(Darja
  Nordberg), PEPPRIG 극세사 청소패드/먼지떨이커버(Zhelin Lian) — 모두 작은
  캡션 크기의 이름+원형 프로필 사진이 리뷰 섹션 위에 배치됨.
- 반면 다이소몰 29건, 지그재그 2건 중에서는 디자이너/제작자 크레딧이 **단 한
  건도 관찰되지 않았다** — 대신 브랜드명(위시플레이스 리빙, 가온해 등)만
  텍스트로 표기됨.

## (b) 디자인 규칙 (IF-THEN 표)

이 표는 "AI가 제품 특성을 분석해 스스로 레이아웃을 선택"할 때 쓸 룰 기반 골격이다.

| # | IF (조건) | THEN (디자인 선택) | BECAUSE (근거) |
| --- | --- | --- | --- |
| 1 | 리뷰 수 ≥ 500건이다 | 리뷰 "건수"를 가격/평점 옆에 큰 숫자로 노출한다 | 리뷰 수가 평점보다 강한 신뢰 신호로 관찰됨 (원리 1) |
| 2 | 리뷰 수 < 10건이다 | 별점 배지를 크게 강조하지 않거나 리뷰 섹션을 축소한다 | n이 적을 때 큰 별점 노출은 오히려 신뢰를 깎아먹는 역효과가 관찰됨 (원리 1의 예외) |
| 3 | 제품이 단일 색상 옵션이거나 색상이 핵심 셀링포인트다 | 히어로 배경색을 제품 컬러와 동일/유사 계열(톤온톤)로 맞춘다 | 배경-제품 컬러 매칭 사진이 더 세련되게 인지됨 (원리 2) |
| 4 | 제품이 "어떻게 쓰는지"가 한눈에 안 보이는 기능성 제품이다(솔/브러시/장갑/클리너 등) | 스튜디오 단독컷 다음에 클로즈업 사용 장면(액션샷)을 최소 1장 배치한다 | 기능 증명 클로즈업이 없으면 구매 확신이 약하다는 관찰이 반복됨 (원리 3) |
| 5 | 제품이 인테리어/라이프스타일 카테고리다(슬리퍼/옷걸이/바구니 등) | 히어로 사진에 소품(옷·러그·식물·음식 등)을 최소 1개 함께 연출한다 | 공간 속 제품 무드컷이 감성적 어필을 강화 (원리 4) |
| 6 | 제품 스펙이 3개 이하의 단순 항목(사이즈/소재/용량)이다 | 표 대신 아이콘+짧은 텍스트 체크리스트 박스로 표현한다 | 표 형태 스펙은 53건 중 전무하며 체크리스트가 시장 표준 (원리 5) |
| 7 | 제품에 사이즈/색상 등 옵션이 2개 이상 있다 | 옵션 선택 UI를 가격 바로 아래, 구매 버튼 바로 위에 배치한다 | 구매 액션이 항상 제품 정보/사진보다 먼저 나오는 구조가 표준 (원리 6) |

### 와이어프레임 B — "감성/라이프스타일 스타일링이 핵심인 제품"
(참고 사례: SKOGSSALLAT/SKOVELSJÖN 슬리퍼 — 소품 배치로 무드를 살리는 유형)

```
┌───────────────────────────────────────────┐
│                                             │
│   히어로 사진 (소품과 함께 연출된 무드컷)      │  ← 규칙5: 옷/러그/식물 등 소품을 곁들여
│   예: 러그+옷걸이 배경 위 슬리퍼               │     "공간 속 제품"을 먼저 보여줌
│                                             │     (기능성 제품과 달리 사진이 최상단)
├───────────────────────────────────────────┤
│  상품명 · 가격                              │  ← 규칙10: 스타일링형은 가격이 사진보다
│                                             │     후순위 — 감성이 먼저
├───────────────────────────────────────────┤
│  사이즈 선택 칩                             │  ← 규칙7: 옵션 UI는 여전히 가격 아래,
│         [ 구매하기 ]                         │     구매버튼 위 원칙 유지
├───────────────────────────────────────────┤
│  디자이너/브랜드 크레딧 (이름+작은 프로필)     │  ← 규칙12: 프리미엄/자사몰 채널이면
│                                             │     감성 신뢰 보강 요소로 배치
├───────────────────────────────────────────┤
│  설명 문단 (소재/촉감 등, 짧은 텍스트)        │
├───────────────────────────────────────────┤
│  질감/바닥재를 살린 보조 사진 1~2장           │  ← 원리4 연장: 인테리어 맥락을 추가로
│  (다른 색상/각도의 스타일링 컷)               │     강화, 기능 클로즈업 아님
├───────────────────────────────────────────┤
│  ★ 평점  리뷰 수                            │  ← 원리1: 스타일링형도 리뷰 수는
│                                             │     여전히 신뢰 신호로 노출됨(후순위)
├───────────────────────────────────────────┤
│  관련 제품 / 같은 시리즈 다른 색상            │
└───────────────────────────────────────────┘
```

두 와이어프레임의 핵심 차이는 "사진의 역할"이다 — A는 사진이 **증거**(기능이
작동한다는 증명)이고, B는 사진이 **무드**(이 제품이 있으면 공간이 이렇게 된다는
상상)다. 두 역할 중 어느 쪽을 먼저 배치할지가 AI 레이아웃 선택 엔진의 첫 번째
분기점이 되어야 한다(원리 3 vs 원리 4).
