## 0. 사이트 정체 확인 (중요한 발견)

`<title>청소용품,생활용품,위탁배송,B2B 매직크린</title>`, "엑셀주문하기",
"위탁배송" 메뉴 존재. **매직크린은 단일 브랜드 D2C 사이트가 아니라
청소용품·생활용품·주방용품·바닥매트·인조잔디를 취급하는 B2B 위탁배송
종합 도매몰**이다. 카테고리 구조가 이번 시장조사 8개 카테고리 중
**생활용품·주방용품·청소용품과 거의 그대로 겹친다** — 즉 매직크린은
이미 이 시장 안에서 실제로 장사하고 있는 당사자다.

## 1~10. CTO 지시 10개 항목 (실제 화면 근거)

| # | 항목 | 실제 관찰 |
| --- | --- | --- |
| 1 | 브랜드 컬러 | 기능 요소(로고·구매 버튼·정책 안내 블록 배경)는 **일관된 블루 톤 하나**로 통일. 화려한 색(레인보우 스타버스트, 초록 리본 배지)은 **프로모션 배너에만 국한**되고 구조적 UI에는 쓰이지 않음. 가격/경고 텍스트는 레드로 강조 |
| 2 | 브랜드 분위기 | 미니멀 프리미엄이 아니라 **정직한 생활용품 도매상** 분위기 — 정보 밀도가 높고, 마스코트 캐릭터(작업복 입은 사람 일러스트)가 등장해 친근함을 더함 |
| 3 | 폰트 스타일 | 표준 한글 산세리프, 크기는 작고 촘촘함. 커스텀 타이포그래피 없음. 강조는 볼드+색상(인라인)으로, 큰 디스플레이 폰트가 아니라 문장 안에서 처리 |
| 4 | 레이아웃 스타일 | **"사진 → 캡션 한 줄" 반복 구조**(긴 세로 스크롤). 카드 그리드는 "디테일 4장" 클로즈업 섹션에만 국한적으로 사용 |
| 5 | 정보 전달 방식 | 사진 위에 텍스트를 얹지 않고 **사진 아래 별도 텍스트**로 설명. 감성 카피보다 사실 진술 위주("설치가 편리합니다", 나무결 특성 등 한계까지 정직하게 명시) |
| 6 | 제품 설명 방식 | 기능 하나당 실제 사진 + 한 문장 효익 캡션. 치수는 라벨이 달린 실측 도해(annotated diagram)로 — 감성 스토리텔링이 아니라 **실측 정보** 중심 |
| 7 | 카테고리 구조 | 5개 대분류(인조잔디/바닥매트/청소용품/생활용품/주방용품) 아래 2~3단계로 깊게 세분화된 도매몰형 구조(예: 바닥매트>PVC롤매트>코일/쿠션/육각/사각/맘보 등) |
| 8 | 브랜드 톤앤매너 | 정중한 존댓말, 고객서비스 지향, 한계·주의사항을 숨기지 않고 먼저 알림. 마스코트로 딱딱함을 완화 |
| 9 | 강조 방식 | (a) 화려한 일러스트 배너로 헤드라인 강조 (b) 색상 리본/배지로 단일 핵심 셀링포인트 강조(예: "식품 용기 사용 가능") (c) 문단 안 인라인 색상·볼드로 경고 강조 |
| 10 | 신뢰를 주는 표현 방식 | **"주문 전 꼭 봐주세요!" 정책 안내 블록**(배송/교환·반품 정책, 파란 카드)이 상세페이지 상·하단에 두 번 반복 배치. 법정 "상품정보 제공고시" 표를 빠짐없이 노출. 소재 한계까지 정직하게 고지 |

## 시장 패턴 vs 매직크린 — 1차 비교 (생활용품 카테고리 조사 완료 후 갱신 예정)

| 항목 | 시장(접근 가능 사이트 기준) | 매직크린 |
| --- | --- | --- |
| Hero | 사진 중심(라이프스타일 연출컷) | **일러스트 배너 + 헤드라인 텍스트** 중심, 사진은 배너 다음 |
| 구매 포인트 | 아이콘+짧은 카피 칩 | 색상 리본 배지 1~2개(칩 여러 개 나열 아님) |
| 특징 설명 | 사진+캡션 카드(그리드) | 사진+캡션이지만 **그리드가 아니라 세로 반복**, 한계까지 정직하게 명시 |
| 스펙표 | 표 디자인(구획·배경색 구분) | **디자인 없는 법정고시 텍스트 표** — 시장 평균보다 스타일링이 약함 |
| 정책/신뢰 | 배송정보 간단 언급 | **정책 안내가 별도 블록으로 두 번 반복** — 시장보다 훨씬 강함 |

**시사점(가설, 생활용품 조사 완료 후 확정)**: 매직크린은 "신뢰·정보투명성"에서
시장 평균 이상이지만, "스펙표 디자인"과 "구매 포인트 시각화"는 시장에서
확인된 더 세련된 패턴(칩/아이콘/그리드)을 아직 안 쓰고 있다 — 이 부분이
Template V1이 "시장 검증 UX + 매직크린 정체성"을 합칠 때 개선 여지다.

## 매직크린 브�드 디자인 토큰 (초안 — Gemini 검토 전, Claude 1차 추출)

```
color.primary        = 브랜드 블루 (버튼·헤더·정책블록 배경)
color.accent.warning  = 레드 (가격·주의 강조)
color.accent.promo    = 프로모션 배너 전용(레인보우/그린 등, 구조 UI에는 안 씀)
typography.base       = 표준 산세리프, 소형 크기, 촘촘한 줄간격
typography.emphasis   = 인라인 볼드 + 색상(디스플레이 폰트 아님)
icon.style            = 리본/배지형 콜아웃(핵심 셀링포인트 1~2개에만), 마스코트 일러스트
card.style            = 사진+캡션 세로 반복(그리드는 클로즈업 디테일 섹션에만 제한적으로)
callout.policy        = 파란 라운드 카드(배송/교환정책) — 상세페이지 상·하단 2회 반복
tone.copy             = 정중한 존댓말, 한계·주의사항을 먼저 밝히는 정직한 어투
```

**이 토큰은 초안이다.** Gemini API 키 확보 후 디자인 디렉터 리뷰를 거쳐
확정하고, 시장 조사(카테고리별 워크플로우, 현재 생활용품 진행 중) 결과와
합쳐 최종 "매직크린 디자인 시스템"으로 발전시킬 계획이다.
