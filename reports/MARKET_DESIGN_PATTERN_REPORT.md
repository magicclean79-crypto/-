# 시장 상세페이지 디자인 패턴 조사 보고서

> CTO 지시(2026-08-07): Template V1 재설계에 앞서, 국내 상위 쇼핑몰 상세페이지의
> UX/디자인 공통 패턴을 조사한다. 목적은 **특정 쇼핑몰 복제가 아니라 여러
> 상세페이지에서 공통으로 나타나는 패턴만 추출**하는 것이다. 이 보고서 검토 후
> Template V1을 새로 설계한다 — **이 문서는 조사 결과만 담으며, 아직 템플릿을
> 수정하지 않았다.**

---

## 0. 조사 방법과 가장 중요한 발견 — "직접 열람은 대부분 막혔다"

8개 카테고리(생활용품·주방용품·욕실용품·수납용품·캠핑용품·산업용품·청소용품·공구)를
각각 독립된 조사원(서브에이전트)이 맡아 실제 상품 상세페이지를 열람하려 시도했다.

**8개 카테고리 전부에서 쿠팡(coupang.com)은 100% HTTP 403으로 차단됐고, G마켓·
11번가도 대부분 403 또는 JS 미렌더링으로 본문을 가져오지 못했다.** 이는 텍스트
기반 HTTP 요청(WebFetch)이 봇으로 감지되어 차단된 것으로 보이며, 브라우저 없이는
국내 대형 오픈마켓의 실제 상세이미지 콘텐츠를 열람할 수 없다는 뜻이다.

실제로 확인 가능했던 것:
- 각 플랫폼이 **셀러에게 공개한 공식 상세페이지 제작 가이드**(쿠팡: 대표이미지
  1000×1000px 흰 배경·상품이 80% 이상 차지, 상세이미지 가로 780~860px 세로
  최대 5,000px 롱폼 / 스마트스토어: 유사 규격) — 이건 추정이 아니라 원문 확인.
- 일부 **소규모 브랜드/전문몰 사이트**(캠핑코어, 데코뷰, 마이크로버, 보오글,
  모노플랫, 다이소몰 등)와 **11번가 개별 상품 2~3건**은 직접 열람 성공.
- **다나와 비교 기획전**(무게·재질·내하중 등 스펙 비교표)는 여러 카테고리에서
  직접 확인 가능했다.
- 나머지는 상세페이지 제작 전문가 블로그/에이전시 글(2차 자료)로 보강했다.

**신뢰도 등급**: 아래 표에서 "정보 배치 순서"·"CTA 배치"·"스펙 표기 방식"은
공식 가이드 원문 + 실제 사이트 다수 교차 확인으로 신뢰도가 높다. "색상 분위기"·
"아이콘 세부 스타일"·"사용 예시 이미지 내용"은 이미지 콘텐츠 자체라 크롤링이
막혀 신뢰도가 낮고 2차 자료 기반 추정 비중이 크다 — **이 구분을 지우지 않고
그대로 아래에 반영했다.**

## 1. 8개 카테고리 공통 패턴 (모든 카테고리에서 반복 확인됨)

| 항목 | 공통 패턴 | 신뢰도 |
| --- | --- | --- |
| 이미지 규격 | 대표 이미지 1:1 정사각형·흰 배경, 상품이 프레임의 80% 이상. 상세 이미지는 가로 780~860px 고정폭의 세로 롱폼 스크롤(최대 3,000~5,000px) | 높음(공식 가이드 원문, 8/8 카테고리 공통 인용) |
| 정보 배치 순서 | 대표이미지+핵심가치 → 핵심 강점 2~4개(아이콘/카피 압축) → 상세컷/스펙 → 구성품/사용법 → 후기·신뢰 요소 → 배송/CTA. **"후킹→설득→신뢰"의 감정 곡선**을 따르는 8단계 구조가 생활용품·주방용품·욕실용품·청소용품·공구 5개 카테고리 자료에서 거의 동일하게 반복 언급됨 | 높음 |
| 구매 포인트 표현 | 장문 설명보다 **숫자를 크게 키운 배지/칩 + 짧은 카피**(예: "1.6kg", "25L", "무이자 할부") 형태가 8개 카테고리 전부에서 확인 | 중간~높음 |
| CTA 배치 | 상세페이지 이미지 자체에는 CTA를 반복 배치하지 않는다 — **오픈마켓 플랫폼이 옵션선택 영역 하단에 고정 구매바를 표준 UI로 강제**하기 때문. 상세페이지 콘텐츠 안에서는 "지금 사야 하는 이유"(할인/한정수량/리뷰수)로 심리적 CTA만 만든다 | 높음(플랫폼 구조상 카테고리 무관하게 동일) |
| 스펙 구성 | 항목-값(key-value) 표 또는 짧은 리스트. 인증(식품용기구마크·KC/KCS 등)이 필요한 카테고리(주방·공구·산업용품)는 법정 표기가 별도 블록으로 분리됨 | 높음 |
| 아이콘 사용 | 아이콘 단독 사용은 없음 — **항상 아이콘+짧은 텍스트 라벨 세트**로 기능/스펙을 표시. 찜하기·공유·리뷰 등 플랫폼 표준 UI 아이콘은 카테고리 무관 동일 | 중간 |
| 레이아웃 | 목록/카드 화면은 그리드, 상세페이지 본문은 세로 풀블리드 스크롤 — 이중 구조가 8개 카테고리 전부에서 일치 | 높음 |

## 3. 종합 해석

1. **정보 구조(순서·CTA·스펙 표기)는 카테고리와 거의 무관하게 표준화**되어 있다 —
   이건 플랫폼(쿠팡/스마트스토어) 자체가 셀러 가이드로 강제하는 부분이라 8개
   카테고리가 다 같다.
2. **차이가 나는 것은 "톤"과 "무엇을 증명하는가"다.** 생활용품·주방용품은 감성/
   신뢰(인증), 캠핑용품은 실사용 상상(야외 연출), 산업용품·공구는 정량 스펙
   신뢰(치수·인증)로 무게중심이 이동한다.
3. **캠핑용품이 유일하게 "사용 예시 표현"에서 강한 실증(직접 열람 확인)을 얻은
   카테고리**다 — 캠핑코어를 직접 열어 "텐트=피칭 연출컷, 의자=사람이 드는 컷"을
   확인했다. 다른 카테고리는 대부분 이미지 접근 차단으로 추정 수준에 머물렀다.
4. **이 조사의 근본적 한계**: 실제 "가장 잘 팔리는" 상품을 판매량 기준으로
   선별해서 본 것이 아니라, 검색으로 찾아지고 접근 가능했던 페이지를 봤다 —
   표본이 편향됐을 수 있다. 신뢰도를 높이려면 실제 브라우저(Playwright)로
   스크린샷을 떠서 이미지 콘텐츠 자체를 시각적으로 분석하는 후속 조사가
   필요하다(각 조사원이 공통으로 이 방법을 후속 제안했다).

## 4. Gemini 리뷰어 투입 시점 (제안, 결정 아님)

이번 조사는 텍스트 패턴 정리이므로 Gemini의 역할(폰트·여백·사진배치·색상·
모바일UX 평가)이 아직 적용될 대상(실제 렌더링된 목업)이 없다. **Template V1
후보 시안이 나온 뒤 Gemini 디자인 리뷰를 투입하는 것을 제안**하며, 이 보고서
검토 후 CTO의 Template V1 설계 방향 확정을 기다린다.

## 5. 다음 결정이 필요한 것 (CTO 검토 대기)

- 이 보고서의 카테고리별 차이(표 2)를 Template V1(단일 기본형)에 어떻게
  반영할지 — 예: 캠핑/생활용품처럼 "감성/연출" 비중이 큰 쪽을 기본으로 할지,
  공구/산업용품처럼 "정량 스펙" 비중이 큰 쪽을 기본으로 할지.
- 표본 편향 문제를 해소하기 위해 Playwright 스크린샷 기반 후속 조사를 진행할지
  (추가 시간·비용 소요).
- Gemini API 키 확보 방법(기존 staging `.env`의 `LLM_PROVIDER=gemini` 설정을
  재사용할 수 있는지 확인 필요).

각 카테고리의 전체 조사 원문(항목별 근거 URL 포함)은 대화 로그에 보존되어 있으며,
요청하시면 카테고리별 전문을 이 문서에 추가로 첨부하겠습니다.
